# Welcome to JuliaNeutrino

JuliaNeutrino is an organization dedicated to neutrino physics in Julia: simulating long-baseline oscillation experiments, computing their sensitivities to standard and new physics, and connecting neutrino mass models to oscillation parameters.

## Looking for a package?

- Simulate oscillation experiments ⚛️: [GLoBES.jl](https://github.com/JuliaNeutrino/GLoBES.jl), a Julia port of the [GLoBES](https://www.mpi-hd.mpg.de/personalhomes/globes/) library. It computes oscillation probabilities (including non-standard interactions and decoherence), event rates and χ² sensitivities, and ships with the DUNE configuration.
- Build neutrino mass models 🧪: [NeutrinoMassModels.jl](https://github.com/JuliaNeutrino/NeutrinoMassModels.jl), particle models written as Mathematica-style model files, their tree-level spectra, and mass mechanisms (seesaw, scotogenic) that turn model parameters into oscillation parameters for GLoBES.jl.

## Looking for tutorials?

🥋: All packages have their own documentation. The [GLoBES.jl documentation](https://julianeutrino.github.io/GLoBES.jl/dev) has a tutorial that follows the tour of the C GLoBES manual.

📓: The [GLoBES.jl notebooks](https://github.com/JuliaNeutrino/GLoBES.jl/tree/main/notebooks) open in Google Colab, so you can try the package without installing Julia.
